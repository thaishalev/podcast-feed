Privacy Policy

Thai's Weekly Brief publishing tool · last updated 18 November 2026

What this app is

The Thai's Weekly Brief publishing tool is a personal automation run by Thai Shalev to produce and distribute the podcast Thai's Weekly Brief. It is not offered to the public and has no other users.

Google data it accesses

  • Gmail (send only): sends the weekly episode email from the owner's own account. It does not read, search or delete any email.
  • Google Drive (files created by the app only): uploads each episode's audio file to a folder the app created, and removes old episode files it uploaded itself. It cannot see any other file in the Drive.

What is stored and shared

The access token is stored only on the owner's own computer. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models. The list of people who receive the episode email is kept privately by the owner and is used only to send that email.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access or data

Access can be revoked at any time at myaccount.google.com/permissions. To stop receiving the episode email, or for any question about this policy, write to shalevthai@gmail.com.
